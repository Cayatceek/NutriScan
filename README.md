# NutriScan

Android-приложение для сканирования штрихкодов и состава продуктов. Проект объединяет поиск продуктов, распознавание текста, анализ ингредиентов и историю сканирования.

## Возможности и модули

- Сканирование штрихкодов и OCR через CameraX и ML Kit.
- Поиск информации о продуктах через Open Food Facts.
- Локальный кеш и история на Room.
- Анализ аллергенов, ингредиентов, Nutri-Score и признаков halal.
- Экраны результатов, истории, справочника добавок и настроек.
- Локализация и настройки через DataStore.

## Стек

Kotlin, Jetpack Compose, Material 3, ViewModel, Room, Retrofit, OkHttp, CameraX и ML Kit. В зависимостях также присутствует Firebase Auth.

## Сборка

1. Откройте корень репозитория в Android Studio с поддержкой используемых Gradle/Android Gradle Plugin.
2. Установите Android SDK 36 и выполните Gradle Sync.
3. Выберите устройство с Android 10 (API 29) или новее.
4. Запустите конфигурацию `app`.

Из терминала:

```bash
# Linux/macOS
bash gradlew :app:assembleDebug
bash gradlew :app:testDebugUnitTest

# Windows
gradlew.bat :app:assembleDebug
gradlew.bat :app:testDebugUnitTest
```

Для проверки камеры требуется устройство с камерой и выданными разрешениями. Авторизация и сетевые сценарии требуют отдельной проверки конфигурации сервисов.

## Код

Основной пакет: [com.nutriscan.app](app/src/main/java/com/nutriscan/app/).

- `data/` — API, кеш, сущности и репозитории.
- `domain/` — OCR, разбор состава и правила анализа.
- `ui/` — экраны, компоненты и тема.
- `viewmodel/` — состояние экранов.
- `localization/` — языки интерфейса.

Серверный проект: [backend-NutriScan](https://github.com/Cayatceek/backend-NutriScan). Наличие двух репозиториев не означает, что все их сценарии уже интегрированы.

## Ограничения

Результаты зависят от полноты каталога, качества распознавания и правил анализа. Они не являются медицинской рекомендацией или сертификатом halal; состав и предупреждения на упаковке остаются первичным источником.
